# 🏆 ScorePilot

**ScorePilot** is a sleek, modern, and high-performance quiz scoreboard application designed for competitions, academic quizzes, and team-based events. Originally built for **DCSE, CDLU Sirsa**, it provides a seamless experience for managing multiple teams, rounds, and real-time standings.

## ✨ Features

- **🚀 Real-time Scoring:** Instantly update points for teams across multiple rounds.
- **📊 Dynamic Leaderboard:** Automatically calculates total scores and ranks teams.
- **📱 Fully Responsive:** Optimized for Desktop, Tablet, and Mobile views with smooth horizontal scrolling.
- **🌓 Dark Mode Support:** Beautiful transitions between light and high-contrast dark themes.
- **💾 Local Persistence:** Scores and team names are saved locally so you never lose progress.
- **🔄 History & Undo:** Mistake friendly! Undo and Redo actions with a full history log.
- **🎨 Modern UI:** Built with **Tailwind CSS** and **Motion** for fluid animations and a premium feel.
- **🏢 Multi-Team Support:** Easily add, rename, or remove participants on the fly.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (Version 18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SahilKhatkar11/scorepilot.git
   cd scorepilot
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

---

## 📖 Usage

1. **Add Teams:** Enter the participant names in the input field.
2. **Set Rounds:** Adjust the number of rounds using the counter in the header.
3. **Score Entry:** Click on any score cell to increase/decrease points or type them manually.
4. **Leaderboard:** Click the **"Reveal Final Winner"** button to see the animated trophy presentation!
5. **Reset:** Use the **"Reset All"** button in the header menus to start a fresh quiz.
